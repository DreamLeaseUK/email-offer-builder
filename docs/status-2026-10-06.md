## 3. Special offers (0.7.1)

**Symptom.** Matt's Passat eHybrid and ID.7 Tourer links were refused as "price on application". Eight of ten live
special offers priced £58–£440 a month too high, with no Special offer badge.

**Cause.** The site's `GET /api/carresults/GetOfferDropdownsForCar` now needs the page's special-offer id as `offerId`.
The page itself sends it: it is the `offer-id` attribute of `<Lease-Term-Config-Form>`, with
`window.motorleaseInit.hotOfferId` as the fallback.

**Fix.**
- `parse-page.ts` reads the id.
- `pricingUrl(slugs, contractType, config, { isVan, offerId, origin })` sends it.
- Every looked-up offer is stamped `source.pricingVersion = PRICING_VERSION` (2). The schema field is optional and
  additive.
- A cached look-up from another version is treated as stale.
- At Send, any url offer priced by an older version is looked up again, however recent (`presend.ts`).
- Compose re-prices a restored draft that holds an old-way offer.
- The lookup warns when its price differs from the page's own schema.org `lowPrice` at the page's default terms.

**Proof.** A live sweep of 10 specials matched each page's `lowPrice` to the penny.

## 8. Gotchas (new)

- **dreamlease.co.uk refuses Node's fetch from Matt's PC (403).** Live diagnostic scripts call `curl` through
  `execFileSync`.
- **`pnpm --filter … exec tsx` fails for scripts.** Use `packages/render/node_modules/.bin/tsx`.
- **Render fixtures expire.** Their `validUntil` dates are now 2099, because 2026 dates had expired and failed three
  API tests.
- **The built-in browser cannot screenshot very tall pages** (the image comes back blank). Use unspam's lightbox
  instead.
- **The Chrome extension blocks output that holds query strings.** Strip `?…` from URLs and read in short slices.
- **A Cloudflare for SaaS hostname lapses** if its DNS is not in place within 7 days. Refresh it, and prefer HTTP
  validation (§5).
