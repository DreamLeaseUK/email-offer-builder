## 2. What the library is now (the decisions)
- **Two surfaces.** Personal shelf (a salesperson's own saves) + shared shelves (central, curated). Search by
  brand/model, most-recently-added first, the **added date on every entry**.
- **Priced live on use, never frozen.** An entry keeps a last-known price for the card; the live price is
  re-fetched from the offer's own URL when it is added to a campaign (`/reprice`, ~free — the site's own JSON), and
  the terms stay editable at that point. No stale price can ship.
- **Dead-URL flag.** Dealer URLs move. Each entry has `urlHealth` (ok / moved / gone). `/reprice` and the daily
  Cron `recheckLibraryUrls()` resolve the source; a moved/gone entry is **blocked** with a hard "URL not current —
  update with the latest" (re-fetch from Compose and re-save).
- **Shelves** (`config/library-shelves.json`, admin-extensible): **PCH latest deals, BCH latest deals, EVs**
  (manual) and **Deals under £300 per month** (**smart** — filtered live on price). "Business" was dropped.
- **Promote = COPY** (Matt): the shared shelf gets its own entry; the salesperson keeps theirs. Admin-only
  (`config/admins.json`); the button only shows for admins.
- **Current / archived**, 6-month purge of the archive (`LIBRARY_ARCHIVE_PURGE_DAYS = 183`) via the retention Cron.
- **Future offer matcher** (later iteration, not built): the entry's attributes are **indexed columns** so the
  matcher is a query over `library_entries`, not a refactor. `libraryFacets(offer)` derives them.
